# Hermetra

[English](./README.md)

## 브랜드 컨셉

**Hermetra**는 `Hermes`와 `Metra`의 합성어입니다.

Hermes는 빠른 이동과 메시지 전달을, Metra는 측정하고 수확하는 행위를 상징합니다. Hermetra는 웹과 모바일 곳곳에 흩어진 정보를 빠르게 찾아내고, 필요한 기준으로 측정하며, 반복 가능한 자동화 흐름으로 수확하는 데스크톱 자동화 도구입니다.

이 프로젝트의 의의는 단순한 크롤링이나 스크래핑을 넘어, 사용자가 원하는 정보를 지속적으로 수집하고 연결하며 관리할 수 있는 자동화 기반을 만드는 데 있습니다.

Hermetra가 집중하는 영역은 다음과 같습니다.

- 웹/모바일 자동화 스크립트 실행
- 브라우저와 모바일 자동화 흐름의 연동
- 뉴스, 채용, 상품, 하이퍼링크 정보 수집
- 반복적인 정보 수집 작업을 재사용 가능한 시나리오로 전환

브랜드 방향성은 **빠른 탐색**, **정확한 측정**, **자동화된 수확**입니다.

## Quick Start

```bash
npm install
npm run dev        # HMR이 적용된 Electron 개발 모드 실행
npm run build      # main / preload / renderer 번들링
npm run typecheck  # tsc -p tsconfig.node.json && tsc -p tsconfig.web.json
```
