## 회차 2 — 사이드바 액센트 제거 · 다크 입체감 복구

- 기준 커밋: `263fb04` (chore(harness): clear the task baton slug)
- 범위: 시각 토큰(면 단차·그림자) 재조정 + 사이드바 구조
- 계기: 유저 지적 두 가지 — ⑴ 선택된 내비 항목에 청록 강조선이 남아 있다(액센트 금지를
  두 번 말했는데 "카드가 아니다"로 해석해 남긴 것), ⑵ 다크 테마에 입체감이 없다.

### 무엇이 잘못돼 있었나

| 측정 | 값 | 뜻 |
|---|---|---|
| 다크 바탕 → 카드 상대휘도 대비 | **1.15:1** | 사실상 같은 색. 단차가 없다 |
| 다크 카드의 1px 링·그림자 | `hsl(0 0% 0%)` 계열 | 거의 검정인 바탕 위의 검정 = 신호 0 |

라이트는 그림자가 일을 하고 있었지만(1.24:1) 다크는 밝기 단차도 그림자도 없었다.

### 고친 것

- 면 단차를 **약 1.4:1** 로 다시 잡았다(사이드바 → 바탕 → 상단바 → 카드 → hover).
- 다크의 가장자리를 **빛으로** 그린다 — 흰색 저투명도 1px 링 + 위쪽 하이라이트.
  아래 그림자는 남기되 유일한 단서로 쓰지 않는다.
- 다크 면의 채도를 18% → 11% 로 낮춰 청록 기운을 뺐다(중립 슬레이트).
- 사이드바에서 액센트를 전부 제거: 그룹 표시 점, 선택 행의 강조선 둘 다.
- 선택 상태를 **눌린 자리**로 바꿨다 — 어두운 채움 + 안쪽 그림자 + 굵은 글자.
  흑백으로 봐도 구분된다.
- 내비 항목을 **영역별 카드 3장**으로 묶었다(유저 요청).
- 카드가 밝아지면서 다크 배지 4종이 4.5:1 밑으로 내려가 토큰을 올렸다
  (web·mobile·bridge·danger·success·보조 글자·placeholder).

| 타입·lint·테스트·빌드 | `npm run check` | PASS (28파일 / 280개 — 사이드바 4개 추가) |
| E2E | `npm run test:e2e` | PASS (11개) |
| 드리프트 검사 | `npm run sweep` | PASS (5/5) |
| 화면 시각 판정 | `surface-verify` | 캡처 54건 · 차단 0 · 관찰 12 |
