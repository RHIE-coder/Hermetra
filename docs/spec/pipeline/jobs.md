# `pipeline.jobs` — 작업

라우트 `/pipeline/jobs` · 컨테이너 `page-pipeline-jobs` · 사이드바 `nav-pipeline-jobs`

**아직 껍데기다** (`README.md` "지금 상태").

들어와야 하는 것: 소스 · 수집 · 처리 · 저장소를 하나로 잇는 **실행 플로우**를 등록해 두는
자리(즐겨찾기)이자, 지금 돌고 있는 작업을 지켜보는 자리. 정의와 실행 이력을 한 화면에 두기로
했고, 쪼개는 판단은 IPC 계약이 생길 때 다시 본다 — 근거는 `README.md` 의 이름 규칙 절.

이 화면이 내용을 가질 때 채운다: 플로우 하나의 데이터 모양, 실행 상태의 값 집합, 저장 위치
(정의는 자산이므로 워크스페이스, 실행 상태는 살아있는 값), 그리고 그때의 인수조건.
