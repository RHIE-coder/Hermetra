# `pipeline.ingestion` — 수집

라우트 `/pipeline/ingestion` · 컨테이너 `page-pipeline-ingestion` · 사이드바 `nav-pipeline-ingestion`

**아직 껍데기다** (`README.md` "지금 상태").

들어와야 하는 것: 소스에서 데이터를 꺼내 **원천 데이터**로 만드는 단계. 처리 이전이고,
꺼낸 그대로를 뜻한다 — 여기서 모양을 바꾸기 시작하면 원천이 아니게 된다.

이 화면이 내용을 가질 때 채운다: 수집 규칙 하나의 데이터 모양, 소스와의 관계(하나가 여럿을
갖는가), 증분 수집의 기준점, 실패·재시도 규칙, 그리고 그때의 인수조건.
