# `pipeline.processing` — 처리

라우트 `/pipeline/processing` · 컨테이너 `page-pipeline-processing` · 사이드바 `nav-pipeline-processing`

**아직 껍데기다** (`README.md` "지금 상태").

들어와야 하는 것: 원천 데이터를 뒤 단계가 기대하는 모양으로 바꾸는 단계. 입력이 원천이고
출력이 저장소로 간다는 점이 이 화면의 위치를 정한다.

이 화면이 내용을 가질 때 채운다: 처리 단계 하나의 데이터 모양, 여러 단계를 잇는 방식,
입력·출력 스키마를 어디까지 강제하는가, 실패한 레코드를 어디로 보내는가, 그리고 그때의
인수조건.
