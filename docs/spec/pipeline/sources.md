# `pipeline.sources` — 소스

라우트 `/pipeline/sources` · 컨테이너 `page-pipeline-sources` · 사이드바 `nav-pipeline-sources`

**아직 껍데기다** (`README.md` "지금 상태").

들어와야 하는 것: 데이터가 나오는 곳의 목록 — API 엔드포인트, 그리고 크롤링·스크래핑 대상
사이트. 파이프라인에서 유일하게 바깥 세계를 가리키는 화면이라, 자격 증명과 접근 실패를
어떻게 다루는지가 이 화면의 핵심이 된다.

이 화면이 내용을 가질 때 채운다: 소스 하나의 데이터 모양(종류별로 다른 필드), 비밀값을 어디에
두는가(변수의 private 쪽과의 관계), 연결 확인 동작, 그리고 그때의 인수조건.
