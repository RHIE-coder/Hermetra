라우트 `/pipeline/insights` · 컨테이너 `page-pipeline-insights` · 사이드바 `nav-pipeline-insights`

토큰(`c1`~`c6`)과 어떻게 이어지는가, 리포트를 내보내는 형식, 그리고 그때의 인수조건.
