입력 {gate-report}를 읽는다 ({intake}가 있으면 원래 요구와 대조).

체크리스트 4항목을 채워 유저에게 보인다 — 항목당 짧게, 쉬운 말로:

1. **요구했던 것** — 원래 요구가 무엇이었나 (intake 기준, 없으면 유저 요청 문장).
2. **완료한 것** — 무엇을 만들었고 무엇으로 검증했나 (gate 결과 요약 포함).
3. **남은 것** — 미완·후속 작업·알려진 한계. 없으면 "없음"이라고 명시.
4. **조언** — 다음에 하면 좋을 것, 발견한 개선 기회. 억지로 만들지 않는다.

과장 금지: 실패했거나 건너뛴 것이 있으면 그대로 적는다. "대체로 됐다"는 말 대신
무엇이 되고 무엇이 안 됐는지를 가른다.
